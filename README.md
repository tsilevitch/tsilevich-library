# Библиотека Анны Цилевич

Публичные публикации о закупках: поиск, словарь, ссылки на оригиналы в Telegram.

Сайт: https://tsilevitch.github.io/tsilevich-library/

Поиск выполняется в браузере. Сайт не использует API, LLM, cookies или аналитику посетителей. Хостинг может вести стандартные журналы запросов.

В репозитории только публичная статическая версия. Исходные тексты публикаций принадлежат Анне Цилевич. Открытый просмотр не означает предоставления лицензии на их переиздание.

Ассистент размечает посты по пятницам в 13:10 МСК. GitHub проверяет готовый публичный каталог ежедневно в 13:25 МСК и публикует только изменения. Дополнительные проверки нужны для доставки после сбоев; повторных обращений к ИИ нет. GitHub может задерживать запуск расписания. Вручную: Actions → Update and publish library → Run workflow.
